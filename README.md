# PIN Scanner (Android)

Offline Android app for reading prepaid top-up codes, with local history
and a one-click `.txt` export.

## Build an APK in the cloud

1. Upload this repository to GitHub (private is fine).
2. **Actions -> Build APK -> Run workflow**.
3. Download the `pin-scanner-apk` artifact and install the APK.

If the build fails, open the red run and copy the lines starting with `e:`
or `FAILURE:` — those name the file and line to fix.
